# Data Science Portfolio

This repository powers my GitHub Pages portfolio website:
**[https://zjlupupgo.github.io/data-science-portfolio](https://zjlupupgo.github.io/data-science-portfolio)**

It showcases the data-science projects I build as part of my studies at the
University of Macau (CISC7204).

## How this site is built

- `index.md` is the website entry point (GitHub Pages reads it from the root).
- `figures/` holds the images embedded in the portfolio.
- The site is published from the **main** branch, **/ (root)** folder, via
  *Settings → Pages → Deploy from a branch*.
